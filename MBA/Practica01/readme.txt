Hay tres programas ACE, LIFE y LIFE2, los tres son programas de NetLogo

ACE
se puede elegir el tamaño de la condición inicial con el slider tamanio
se puede elegir el tiempo de evolución con el slider tiempo-evolución
se puede elegir el tipo de frontera con el chooser frontera
se puede elegir si la condición inicial sea aleatorio o no con el switch aleatorio
se puede elegir la regla del automata con el slider regla
se debe dar click en el botón setup para cargar las condiciones iniciales y los cambios de las opciones de arriba
se pueden usar los botones pintar blanco y pintar negro para modificar la condición inicial luego de usar setup
por ultimo para que el autómata evolución se debe dar click en el botón go

LIFE
se puede elegir el tamaño x del mundo con el slider tamanio-x
se puede elegir el tamaño y del mundo con el slider tamanio-y
se puede elegir la probabilidad de que una celda este viva al inicio con el slider proba
se puede elegir el tipo de frontera con el chooser frontera
se debe dar click en el botón setup para cargar mundo con las opciones de arriba y también pintar las celdas
por ultimo para que las celdas evolucionen se debe dar click en el botón go

LIFE2 (este programa es similar a LIFE pero con estructuras para cargarse)
para cargar la compuerta NOT se debe dar click en el botón cargar-not
para cargar la compuerta AND se debe dar click en el botón cargar-and
nótese que el tamaño del mundo y las fronteras no se pueden modificar en este problema para evitar problemas al cargar las compuertas y evitar errores en la ejecución
se pueden usar los botones colorear-celda green y colorear-celda black para modificar algunos de los valores de las compuertas (los valores de verdad de A y B) luego de usar el botón para cargar una compuerta
por ultimo para ver el funcionamiento de la compuerta se debe dar click en el botón go
