Hay varios programas de NetLogo segregacion, segregacion-dos, segregacion-tres, termitas, termitas-color, termitas-color-dos, termitas-random, termitas-tick y hormigas

segregacion
se puede elegir el tamaño del mundo con el slider tamanio
se puede elegir la cantidad de agentes en el mundo con el slider densidad
se puede elegir el porcentaje de similitud que necesita un agente para estar satisfecho con el slider similitud
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

segregacion-dos
funciona de manera similar que segregacion
tiene el mismo slider de tamanio y densidad
se puede elegir el porcentaje de similitud mediante una distribución normal la cual se puede modificar mediante los sliders media y desviacion
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

segregacion-tres
funciona de manera similar que segregacion-dos solo que ahora hay tres tipos de agentes
tiene el mismo slider de tamanio y densidad
se puede elegir el porcentaje de la población que será de cada tipo de agenete con los sliders porcentaje-rojo, porcentaje-azul y porcentaje-verde
se puede elegir el porcentaje de similitud para cada tipo de agente mediante una distribución normal la cual se puede modificar mediante los sliders media y desviacion (para los agentes rojos es con media-roja y desviacion-roja, de manera similar para los agentes azules y verdes)
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

termitas
se puede elegir el tamaño del mundo con el slider tamanio
se puede elegir la cantidad de astillas en el mundo con el slider densidad
se puede elegir la cantidad de agentes en el mundo con el slider poblacion
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

termitas-tick
funciona de manera similar que termitas solo que ahora hay ticks y graficas
tiene el mismo slider de tamanio, densidad y poblacion
se puede elegir si durante la ejecución se va a contar la cantidad de cúmulos con el switch contar
se puede elegir cada cuantos ticks se va a contar la cantidad de cúmulos y termitas cardango con el slider ciclos
se puede dar click en el botón mostrar durante la ejecución para que se imprima la cantidad de cúmulos
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

termitas-color
funciona de manera similar que termitas solo que ahora hay dos tipos de astillas
tiene el mismo slider de tamanio, densidad y poblacion
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

termitas-color-dos
funciona de manera similar que termitas-color solo que ahora las termitas pueden recoger cualquier tipo de astillas
tiene el mismo slider de tamanio, densidad y poblacion
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

termitas-random
funciona de manera similar que termitas solo que ahora las termitas saltan a una posición aleatoria luego de dejar una astilla
tiene el mismo slider de tamanio, densidad y poblacion
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go

hormigas
se puede elegir el tamaño del mundo con el slider tamanio
se puede elegir la cantidad de agentes en el mundo con el slider densidad
se puede elegir la ganancia que se usara en el función de activación con el slider ganancia
se puede elegir el valor de S que se dará con la activación espontanea con el slider espontaneo
se puede elegir la probabilidad de que una hormiga se active de manera espontanea con el slider proba-actividad
se debe dar click en el botón setup para cargar mundo con las opciones de arriba
por ultimo para que el modelo evolucione se debe dar click en el botón go
